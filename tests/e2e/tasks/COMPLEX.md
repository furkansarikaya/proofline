I'd like to be able to tag the books in my reading list. On the page I want to add one or more tags to a book (for example "sci-fi" or "book club"), see each book's tags in the list, remove a tag from a book, and filter the list so it only shows books that have a given tag. The tag filter should work together with the existing status filter and with paging. Tags are not case-sensitive: "Sci-Fi" and "sci-fi" are the same tag. When a book is deleted, its tags should no longer point to it. The API should offer the same things the page can do.

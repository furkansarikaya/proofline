# Image and font ledger

Every image on the page and every self-hosted font has a row. A row is valid only when `file`, `license` and `credit` (images) or `source` (fonts) are filled. Own work: license `own`, credit the author. A library photo: its original address as source_url, its stated licence, the photographer as credit, and the page it appears on. A generated image: license `generated`, credit `tool: <name>; prompt: <text>`. Fonts: the licence read from the package or the licence directory. Copy to `docs/design/IMAGES.md`.

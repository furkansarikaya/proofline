# Third-party content in the repository

**Status:** Rejected, with a recorded exception.

No copied prose, prompts, skill text or scripts from other projects, and
no third-party project names in documentation, skills, changelogs or
generated sites.

## The exception

Data files vendored unchanged under a permissive license, with the
original license text and source commit in a single notices file. That
notices file is the only place source names appear, and a sync script
keeps the copies identical to the source.

## Instead

Ideas from other projects are welcome; they are rewritten in proofline's
own voice and fitted to its evidence rules.

# Content SEO and analytics features

**Status:** Rejected.

proofline does not choose keywords, write marketing copy for ranking, or
add analytics to a project on its own.

## Allowed

- Technical SEO that can be measured (titles, descriptions, canonical,
  hreflang, sitemap, robots, structured data) as part of visual-proof.
- Detecting analytics that loads before consent, when the project already
  contains analytics.
- Keyword research through product-discovery, where search volumes count
  as facts only when they come from a recorded data source.
